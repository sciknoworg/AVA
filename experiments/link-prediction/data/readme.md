# Datasets

The datasets used in this project are:

* YAGO3-10
* FB15K
* WN18RR

## Download

These datasets are not included in this repository.

Please download them from:

https://github.com/yao8839836/kg-bert

Navigate to the `data/` directory in that repository and download the required datasets.

## Expected Structure

After downloading, place the datasets in this folder with the following structure:

```
data/
  FB15K/
  WN18RR/
  YAGO3-10/
```

Each dataset folder should contain files such as:

* `train.tsv`
* `dev.tsv`
* `test.tsv`
* `entities.txt`
* `relations.txt`
* `entity2text.txt`
* `relation2text.txt`
